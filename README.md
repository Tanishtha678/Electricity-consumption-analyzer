# Electricity Consumption Analyzer
## About the Project
This is a Python project made as part of my BCA Data Science coursework. The aim of this project is to understand household electricity consumption using Python and basic data analysis techniques.
The project uses Pandas and NumPy to analyze electricity usage in different rooms over six months. It calculates total and average consumption, estimates electricity costs, compares monthly usage, identifies unusually high consumption, and estimates possible savings.
It also provides simple electricity conservation suggestions and generates a chart to visualize monthly consumption.

## Features
- Calculate total electricity consumption.
- Estimate electricity costs using an assumed rate per unit.
- Calculate average electricity usage by room.
- Find the month with the highest consumption.
- Identify the room with the highest total consumption.
- Calculate each room's percentage contribution.
- Detect unusually high usage using a simple threshold.
- Calculate month-to-month percentage changes.
- Estimate potential electricity and cost savings.
- Generate a monthly electricity consumption chart.
- Display simple electricity conservation suggestions.
